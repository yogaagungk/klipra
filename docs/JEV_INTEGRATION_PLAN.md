# Jev highlight selection

Upstream's `main.get_viral_clips` builds transcript windows, scores them and requests detailed clip proposals using Gemini or an OpenAI-compatible text service. `clip_selection.py` provides duration, count and overlap helpers; `gemini_worker.py` defines output schemas. Frame-based layout selection and silent-video analysis still use Gemini. See `docs/architecture/clip-selection.md`.

The self-hosted TypeSafe Jev provider implements a separate flow: local transcript-word candidate generation → Jev scoring → boundary and overlap checks → clips presented for human review. Rendering uses the existing OpenShorts renderer. The ranker sends each candidate's transcript to TypeSafe and requests six typed scores for hook, standalone comprehension, emotional impact, information value, transcript clarity, and boundaries. Boundaries are word-aligned; they are not necessarily complete thoughts. An excerpt supplies the title and descriptions; no generated hook or explanation is claimed. There is no acoustic speech-clarity assessment and no generative title model in this provider. See `docs/JEV_PROVIDER.md` for configuration and limitations.

The adapter uses TypeSafe's documented System One API, not an OpenAI-compatible chat endpoint: https://api.typesafe.ai/redoc . Candidate count is limited, errors fail the job, and no provider is silently substituted. The original Gemini and OpenAI-compatible paths remain available. Sparse or silent videos still need Gemini vision; without a Gemini key frame-based layout selection falls back.

Future improvements: select sentence-aware boundaries; improve coverage for long recordings; evaluate scoring and calibration on authorized Indonesian and English podcasts; expose per-dimension scores and human review before rendering; add a real clip-quality evaluation dataset; support a separate generator for titles and descriptions. Mocked tests cannot establish model quality or API availability. Consider TypeSafe's data handling, cost and rate limits before sending content: https://help.typesafe.ai/articles/5974925716-how-is-submitted-data-used-or-retained .
